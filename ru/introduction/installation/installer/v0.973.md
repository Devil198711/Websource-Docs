# Установка CMS Websource

Веб-установщик проверяет сервер, получает актуальную beta-версию CMS Websource и помогает выполнить первоначальную настройку сайта.

## Перед началом

Установщик должен находиться непосредственно в корне сайта, указанном веб-сервером как `DocumentRoot`.

Во время завершения установки содержимое корня заменяется файлами CMS. Не запускайте установщик в каталоге действующего сайта без резервной копии.

Перед установкой:

1. Создайте резервную копию файлов сайта.
2. Подготовьте отдельный или пустой корень сайта.
3. Создайте базу данных MySQL или MariaDB.
4. Создайте пользователя базы данных с правами на создание таблиц и запись данных.
5. Убедитесь, что сервер может выполнять исходящие HTTPS-запросы.
6. Направьте домен на подготовленный корень сайта.

## Системные требования

| Требование | Минимальное значение |
|---|---|
| PHP | `8.3.0` или новее |
| Архитектура PHP | 64-битная |
| База данных | MySQL или MariaDB |
| Свободное место | не менее `50 MB` |
| Веб-сервер | Apache, LiteSpeed или Nginx |

Необходимые расширения и возможности PHP:

- PDO MySQL
- cURL с поддержкой HTTPS
- ZIP
- mbstring
- fileinfo
- GD с поддержкой JPEG, PNG, GIF и WebP
- EXIF
- iconv
- ctype
- OpenSSL
- сессии и cookie
- загрузка файлов

Временный каталог PHP и корень сайта должны быть доступны для записи. Установщику необходимы права на создание, переименование и удаление файлов и каталогов.

Для подготовки архива и резервной копии во время установки может потребоваться больше свободного места, чем указанный минимум.

## Размещение установщика

Скачайте архив установщика на официальной [странице загрузки](https://cmswebsource.com/ru/download).

Распакуйте его содержимое непосредственно в корень сайта. После распаковки в корне должны находиться:

- `index.php`
- папка `action`
- папка `assets`
- папка `class`
- папка `lang`

Не размещайте эти файлы в дополнительной вложенной папке.

Откройте домен сайта в браузере. Если установщик размещён правильно, появится стартовая страница мастера Websource.

## Шаги установки

### Выбор языка

В верхней части страницы выберите язык установщика. Выбранный язык также используется при создании начальных данных CMS.

### Лицензионное соглашение

Ознакомьтесь с пользовательским лицензионным соглашением.

Для продолжения установки необходимо подтвердить принятие его условий.

### Проверка системы

Установщик автоматически проверяет:

- версию и архитектуру PHP
- наличие обязательных расширений
- поддержку сессий и загрузки файлов
- доступность временного каталога
- расположение установщика в корне сайта
- возможность работы с файлами
- доступное дисковое пространство

Все обязательные проверки должны завершиться успешно.

После изменения конфигурации сервера нажмите «Проверить повторно».

## Подключение к базе данных

Укажите параметры подготовленной базы данных.

| Поле | Описание |
|---|---|
| Сервер | Адрес сервера базы данных. Обычно используется `localhost`. |
| Порт | Порт MySQL или MariaDB. По умолчанию `3306`. |
| Имя базы данных | Имя заранее созданной базы данных. |
| Префикс таблиц | Префикс таблиц CMS. По умолчанию `WS_`. |
| Пользователь | Пользователь базы данных. |
| Пароль | Пароль пользователя базы данных. |

Префикс может содержать латинские буквы и цифры и должен заканчиваться символом `_`. Его максимальная длина составляет `27` символов.

Нажмите «Проверить подключение». Продолжить можно только после успешной проверки.

Используйте пустую базу данных либо префикс, с которым ещё не создавались таблицы CMS. Установщик остановит процесс, если обнаружит конфликт существующих таблиц.

## Создание администратора

Укажите данные главной учётной записи сайта:

| Поле | Требование |
|---|---|
| Логин | От `3` до `99` символов. |
| Email | Действительный адрес электронной почты. |
| Пароль | От `8` до `99` символов. |
| Подтверждение пароля | Должно совпадать с паролем. |

Используйте уникальный пароль, который не применяется на других сайтах.

## Подтверждение

Перед запуском установки проверьте:

- адрес и порт базы данных
- имя базы данных
- префикс таблиц
- пользователя базы данных
- логин администратора
- email администратора

При необходимости вернитесь к нужному шагу через кнопку «Изменить».

Не закрывайте страницу после нажатия «Установить CMS».

## Процесс установки

Установщик последовательно:

1. Проверяет введённые данные.
2. Получает информацию об актуальной beta-версии CMS.
3. Загружает и проверяет архив.
4. Подготавливает файлы CMS.
5. Создаёт таблицы и начальные данные.
6. Создаёт конфигурацию подключения к базе данных.
7. Подготавливает настройки веб-сервера.
8. Размещает CMS в корне сайта.
9. Завершает установку и удаляет файлы установщика.

Дождитесь сообщения об успешном завершении. Не обновляйте и не закрывайте страницу во время выполнения этих операций.

## Настройка веб-сервера

### Apache и LiteSpeed

Установщик автоматически создаёт файл `.htaccess` с необходимыми правилами.

Дополнительные действия обычно не требуются, если сервер разрешает использование `.htaccess`.

### Nginx

Для Nginx установщик выводит готовый блок конфигурации.

1. Скопируйте показанный блок.
2. Добавьте его внутрь блока `server` конфигурации сайта.
3. Проверьте конфигурацию Nginx.
4. Перезагрузите Nginx.
5. Убедитесь, что главная страница и административная панель открываются без ошибок.

Используйте конфигурацию, показанную установщиком для текущей версии CMS, а не правила от другой версии.

## Завершение

После успешной установки нажмите «Перейти к авторизации».

Административная панель доступна по адресу:

```text
/admin
```

Авторизуйтесь с логином и паролем, указанными на этапе создания администратора.

## Возможные проблемы

### Проверка системы не пройдена

Исправьте требования, отмеченные как невыполненные, затем нажмите «Проверить повторно».

Если проверка прав на файлы не пройдена, убедитесь, что PHP может создавать, переименовывать и удалять файлы в корне сайта.

### Не удаётся подключиться к базе данных

Проверьте:

- адрес и порт сервера
- имя базы данных
- логин и пароль
- права пользователя базы данных
- доступность MySQL или MariaDB с веб-сервера

### Обнаружены существующие таблицы

Используйте пустую базу данных или другой префикс таблиц.

Не удаляйте таблицы действующего сайта без резервной копии.

### Не удаётся получить или загрузить версию CMS

Проверьте доступ сервера к исходящим HTTPS-соединениям, работу DNS, cURL и OpenSSL.

### Не открываются страницы после установки

Для Apache и LiteSpeed проверьте поддержку `.htaccess`.

Для Nginx убедитесь, что вы добавили выданный установщиком блок в конфигурацию сайта и перезагрузили сервер.

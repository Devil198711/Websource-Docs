# $WS_Options

`$WS_Options` содержит глобальные настройки CMS в виде ассоциативного массива.

Переменная заполняется автоматически и доступна в файлах темы.

## Поддерживает

- получение названия и описания сайта
- получение адреса сайта
- определение активной темы
- получение текущего языка
- проверку режима разработки
- получение общих настроек CMS

## Быстрый старт

```php
$siteName = $WS_Options['sitename'] ?? '';
$siteUrl = $WS_Options['siteurl'] ?? '';
$language = $WS_Options['language'] ?? 'ru';
```

Создавать или заполнять массив вручную не нужно. CMS загружает настройки до подключения файлов активной темы.

## Основные значения

| Ключ | Описание |
|---|---|
| `sitename` | Название сайта. |
| `description` | Описание сайта. |
| `keywords` | Ключевые слова сайта. |
| `siteurl` | Основной URL сайта. |
| `template` | Название активной темы. |
| `language` | Код текущего языка. |
| `debug` | Состояние режима разработки. |
| `rusurl` | Разрешено ли использование кириллицы в URL. |

Состав массива может отличаться в зависимости от версии CMS, установленных модулей и сохранённых настроек.

## Проверка настройки

Значения переключателей обычно представлены строкой `on` или пустой строкой:

```php
if (($WS_Options['debug'] ?? '') === 'on') {
    echo 'Режим разработки включён';
}
```

## Использование внутри функции

Внутри функции переменную необходимо подключить из глобальной области:

```php
function getSiteName(): string {
    global $WS_Options;

    return (string) ($WS_Options['sitename'] ?? '');
}
```

## Важные замечания

- проверяйте существование ключа перед обращением к нему
- значения настроек обычно представлены строками
- изменение массива не сохраняет настройки в базе данных
- не рассчитывайте на наличие ключей, добавляемых отдельными модулями
- используйте переменную преимущественно для чтения настроек

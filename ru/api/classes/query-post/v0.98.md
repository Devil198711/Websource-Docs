# QueryPost

`QueryPost` предоставляет статические методы для получения параметров текущего POST-запроса. Создавать экземпляр класса не нужно.

## Поддерживает

- проверку наличия параметра
- получение значения с экранированными HTML-символами
- получение исходных строк и массивов
- получение всех параметров POST-запроса

## Быстрый старт

```php
$title = QueryPost::getValue('title');
if ($title !== null) {
    echo '<p>' . $title . '</p>';
}
```

## Проверка параметра

### isset($key): bool

Возвращает `true`, если параметр существует и его значение не равно `null`. Пустая строка и массив считаются переданными значениями.

## Получение значения

### getValue($key): ?string

Возвращает скалярное значение, приведённое к строке, с экранированными HTML-символами. Символы `<`, `>`, `&`, одинарные и двойные кавычки преобразуются в HTML-сущности.

Если параметр отсутствует, равен `null` или содержит массив, возвращается `null`. Метод не проверяет назначение и формат значения.

### getPostArray(): array

Возвращает параметры POST-запроса с сохранением ключей. Каждое значение обрабатывается через `getValue()`: скалярные значения становятся экранированными строками, массивы заменяются на `null`. Вложенные элементы не обрабатываются.

Если параметров нет, возвращается пустой массив.

## Исходные значения

### getOriginalValue($key): mixed

Возвращает значение без обработки, включая массивы. Если параметр отсутствует или равен `null`, возвращается `null`. Предварительный вызов `isset()` не требуется.

### getOriginalPostArray(): array

Возвращает все исходные параметры POST-запроса без экранирования и изменения вложенных массивов. Если параметров нет, возвращается пустой массив.

Для форм с параметрами-массивами используйте методы получения исходных значений и проверяйте типы и содержимое элементов самостоятельно. Исходные значения нельзя выводить в HTML без экранирования.

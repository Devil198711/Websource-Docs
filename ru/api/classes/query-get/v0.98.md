# QueryGet

`QueryGet` предоставляет статические методы для получения параметров текущего GET-запроса. Создавать экземпляр класса не нужно.

## Поддерживает

- проверку наличия параметра
- получение значения с экранированными HTML-символами
- получение исходных строк и массивов

## Быстрый старт

```php
$search = QueryGet::getValue('search');
if ($search !== null) {
    echo '<p>' . $search . '</p>';
}
```

## Проверка параметра

### isset($key): bool

Возвращает `true`, если параметр существует и его значение не равно `null`. Пустая строка и массив считаются переданными значениями.

## Получение значения

### getValue($key): ?string

Возвращает скалярное значение, приведённое к строке, с экранированными HTML-символами. Символы `<`, `>`, `&`, одинарные и двойные кавычки преобразуются в HTML-сущности.

Если параметр отсутствует, равен `null` или содержит массив, возвращается `null`. Метод не проверяет формат значения: например, является ли оно допустимым номером страницы.

## Исходное значение

### getOriginalValue($key): mixed

Возвращает значение без обработки, включая массивы. Если параметр отсутствует или равен `null`, возвращается `null`. Предварительный вызов `isset()` не требуется.

```php
$value = QueryGet::getOriginalValue('tags');
$tags = is_array($value) ? $value : [];
```

Для запроса `?tags[]=php&tags[]=cms` переменная `$tags` содержит массив `['php', 'cms']`.

Каждый элемент массива нужно проверять отдельно. Исходные значения нельзя выводить в HTML без экранирования.
